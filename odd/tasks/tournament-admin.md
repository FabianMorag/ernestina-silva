# Tournament admin
Objective: Enter historical FIFA championship matches through a local admin interface.
Branch: `feat/tournament-admin` · Delivery: exception-ok; semantic work-unit commits, no line cap · Runner: pnpm/Vitest; Prisma migration on local PostgreSQL.

## Specs
- S1 — "El admin tiene que ser usuario y contraseña." "el usuario admin puede ser algo como admin/admin, ya que por ahora será de uso local, eventualmente crearé uno real". Scope: local sign-in, secure server-side authentication, no default production credential. Check: rejected wrong password; accepted local admin; protected API.
- S2 — "Cada partido enfrenta a dos jugadores registrados con sus respectivos equipos." Scope: player/team records and match creation validating distinct registered players and their selected teams. Check: valid match persisted; invalid opponents rejected.
- S3 — "Los partidos tienen un jugador, el equipo que usaron, el campeonato en el que se jugó, contra quien se jugó, resultado." Scope: championship, match score, listing, and admin entry. Check: match round-trip through API and UI.
- S4 — "Además hay algunos campeonatos que además han tenido una fase de grupos e incluso un formato liga previo a las llaves de la copa." Scope: championship stage record (groups, league, knockout) selectable for a match; no automatic brackets or standings assumed. Check: stages persist and appear in entry form.
- S5 — "-podrias configurar el formulario de usuario y contraseña en el swagger?" Scope: document login JSON body and cookie security so Swagger UI can submit credentials and use the browser session for protected operations. Check: OpenAPI login body has required username/password and protected routes reference a defined cookie scheme.
- S6 — "el admin es simplemente para ingresar datos, pero todos los otros endpoints y rutas del frontend son visibles para todos. Además la visual debe ser en español" Scope: preserve authenticated admin writes; add anonymous read-only tournament API and public frontend pages; make all visible frontend copy Spanish. Check: anonymous reads succeed, unauthenticated writes fail, public pages render without login, UI copy is Spanish.
- S7 — "vamos a darle una estetica a este proyecto como se ve en la imagen, por ahora el home será la lista de campeonatos" "la estetica de la app debe con todo oscuro, el fondo blanco de la imagen es porque la generé con ia solamente pero no es parte de lo que deberia ser la web" Scope: use a fully dark visual theme across public pages and admin, retaining dark panels and lime accents; home remains a list of real championships. Do not invent brackets, standings, or statuses absent from stored data. Check: home renders championship cards, all routes have dark backgrounds with readable content, empty/loading/error states remain usable, and championship actions lead to corresponding matches.
